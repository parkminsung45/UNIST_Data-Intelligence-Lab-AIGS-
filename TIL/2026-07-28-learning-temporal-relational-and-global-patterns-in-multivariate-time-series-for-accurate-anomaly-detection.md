## 다변량 시계열 이상 탐지(Multivariate Time Series Anomaly Detection)


**→ 시간적(Temporal), 관계적(Relational), 전역적(Global) 패턴**을 동시에 학습하여 시스템의 정상 상태를 정의하고 오작동이나 이상치를 정확히 찾아내는 최신 AI 분석 기법으로 단일 센서가 아닌 여러 센서나 지표가 얽혀 있는 복잡한 시스템(예: 스마트 팩토리, 서버 모니터링)에서 정밀한 탐지를 수행


### 핵심 패턴 학습 요소 

1. 시간적 패턴 (Temporal Patterns)
- 각 변수(센서)가 시간 흐름에 따라 어떻게 변하는지 추적
- 과거의 데이터가 현재와 미래에 미치는 연속적인 의존성 학습
- 딥러닝에서는 주로 순환신경망(RNN/LSTM)이나 1D/TCN(시간 합성곱 네트워크)을 활용
1. 관계적 패턴 (Relational Patterns)
- 서로 다른 변수들 간의 상관관계나 인과관계를 파악
1. 전역적 패턴 (Global Patterns)
- 국소적 변화 뿐만 아니라 전체 시스템의 넓은 범위에 걸친 문맥(Context)를 아우름
- 개별 데이터의 일시적 튀는 현상(Noise)에 흔들리지 않고 전체적인 거시 흐름 속의 이상을 감지

### 이상 탐지 작동 방식

1. 정상 패턴 학습
- 모델은 주로 정상 데이터를 기반으로 위 세가지 패턴 (시간,관계,전역)의 정상적인 상호작용 방식을 익힘
1. 재구성 및 예측
- 학습된 모델은 입력된 시계열 데이터를 복원하거나 예측하려 시도
1. 이상치 점수 산출
- 실제 데이터와 모델이 예측/복원한 데이터 사이에 큰 오차가 발생하면 이는 정상적인 패턴(시간/관계/전역적 조화)가 깨졌음을 의미하므로 이상치로 판단

# 📌 연구 주제


**Learning Temporal, Relational, and Global Patterns in Multivariate Time Series for Accurate Anomaly Detection**


(다변량 시계열의 시간적·관계적·전역적 패턴을 함께 학습해 이상 탐지 정확도를 높이는 연구)


---


## 1. 배경 — 문제 정의

- **다변량 시계열(Multivariate Time Series)**: 여러 개의 단변량 시계열을 시간축으로 함께 쌓은 데이터
    - 예: 헬스케어의 여러 생체 신호, 산업 현장의 여러 센서 값
- **이상 탐지(Anomaly Detection) task 정의**
    - 슬라이딩 윈도우(sliding window)로 구간을 잘라 입력받음
    - 해당 시점/구간이 이상인지 판별
- **학습 방식**: 정상 데이터의 패턴만 학습 → 정상 상황을 잘 예측하도록 모델을 학습 → 예측이 크게 빗나가는 지점을 이상(anomaly)으로 판단 (self-supervised/forecasting 기반 접근)

---


## 2. 정상 패턴을 잘 모델링하기 위한 3가지 핵심 축


| 축                    | 설명                                        |
| -------------------- | ----------------------------------------- |
| **Temporal (시간적)**   | 하나의 시계열 내에서 시간 흐름에 따른 패턴                  |
| **Relational (관계적)** | 서로 다른 시계열(변수)들 간의 상호 관계                   |
| **Global (전역적)**     | 국소적(local) 윈도우만으로는 보이지 않는, 전체 시계열의 전반적 특성 |


---


## 3. 각 축을 모델링할 때의 어려움


### (1) Temporal 모델링의 어려움

- **변수별로 노이즈 수준이 다름**: 어떤 시계열은 변동폭이 크고, 어떤 시계열은 완만함 → 이 차이를 반영해야 함
- **시간 순서 정보가 중요**: 값들의 순서를 뒤섞으면 (예: 1234 → 1324) 의미가 달라짐 → 시점 순서(order)를 보존하는 임베딩 필요

### (2) Relational 모델링의 어려움

- 정상 상황에서는 시계열 간 관계가 일정하게 유지되다가, **관계가 깨지는 순간이 이상 탐지의 중요한 단서**가 됨
    - 예: 평소 함께 움직이던(동조하던) 두 변수가 어느 시점부터 어긋나기 시작
- 국소적인(local) 윈도우만 보면 서로 다른 변수 쌍이 비슷하게 보일 수 있어, 단순히 국소 구간 정보만으로 관계를 판단하면 오판 위험

### (3) Global 정보의 필요성

- 국소 윈도우에서는 관찰되지 않는, 시리즈 전체의 내재적 특성을 함께 반영해야 관계 판단의 정확도가 올라감

---


## 4. 기존 연구와의 차이

- 기존 연구들은 각 축(시간/관계/전역)을 개별적으로 다루는 모듈은 있었음
    - 시간 축: RNN 계열, 혹은 여러 스케일(multi-scale)로 시간 패턴을 보는 방법들
    - 관계 축: 시계열 간 관계를 그래프 등으로 보는 방법들
- 이 연구는 **이 3가지 축을 하나의 프레임워크로 통합**하는 것이 핵심 기여

---


## 5. 제안 프레임워크 구조 (추정 요약)

1. **입력**: 슬라이딩 윈도우 단위로 다변량 시계열 구간 입력
2. **Global Context 반영**: 관계를 보기 전에, 각 시계열의 전반적 특성을 반영한 **global context 임베딩**을 만들어 이후 관계 계산에 사용
3. **Temporal 모듈**: 윈도우 내 시점들을 순서 정보를 보존하며 인코딩 (FiLM 같은 modulation 방식으로 윈도우 임베딩을 조정하는 방식 언급됨)
4. **Relational 모듈**: Global context가 반영된 임베딩끼리 관계(예: attention/유사도 기반)를 계산
5. **출력**: 다음 시점(next timestep) 값을 예측 → 실제 값과의 차이(residual)를 이상 점수로 사용

---


## 6. 실험 결과 요약

- **정성적 분석**: 사람이 보기에 직관적으로 해석 가능한 형태로 관계/패턴을 시각화하여 설명력 확보
- **Ablation (구성요소 제거 실험)**: 시리즈 인덱스를 맞추는 보조 과제(auxiliary task)가 오히려 학습에 방해가 됐을 가능성 언급 (일부 설계 선택이 성능에 부정적 영향)
- **하이퍼파라미터 민감도**: 두 로스(loss) 항의 가중치를 동일하게 두면 성능이 좋지 않음 → 가중치 튜닝이 중요
- **온라인 추론(online inference) 상황**에서도 모델 성능 확인 → 안정적인 결과
- 참고: 공개 데이터셋은 대체로 샘플링 주기가 성긴(예: 1초 단위) 경우가 많아 현재는 큰 문제가 없지만, 향후 고빈도 데이터에서는 이슈가 될 수 있다는 언급

- 좋은 성능과 효율적인 연산 시간을 동시에 달성
