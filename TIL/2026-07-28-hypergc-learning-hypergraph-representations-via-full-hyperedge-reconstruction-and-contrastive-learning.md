# HyperGC 학습 노트


---


## 1. 왜 "하이퍼그래프"가 필요한가?


일반 그래프는 이렇게 정의됩니다.


$$
G = (V, E), \quad e = (u, v),\ u, v \in V 
$$


엣지 하나가 정확히 노드 2개만 연결합니다. 그런데 현실에는 "논문 저자 3명", "이메일 참여자 5명"처럼 동시에 여러 명이 얽힌 관계가 많습니다. 이걸 일반 그래프로 표현하려면 2명씩 짝지어 여러 엣지로 쪼개야 하는데, 이 과정에서 "원래 이들이 하나의 사건으로 묶여 있었다"는 정보가 사라집니다.


**하이퍼그래프**는 엣지 하나가 임의 개수의 노드를 묶을 수 있도록 확장한 구조입니다.


$$
G = (V, E), \quad e_i \subseteq V, \quad |e_i| \geq 2 
$$


여기서 $e_i$가 **하이퍼엣지**입니다. (예: $e_1 = {v_1, v_2, v_3}$)


---


## 2. 하이퍼그래프 확장(Expansion) 방법


하이퍼그래프는 정보를 잘 담지만, 대부분의 GNN(그래프 신경망)은 "일반 그래프"를 입력으로 받습니다. 그래서 하이퍼그래프를 일반 그래프로 변환(확장)한 뒤 GNN을 태우는 게 실용적이며, 이 변환에서 어떤 방법이 정보를 덜 잃는지가 핵심 논점입니다.


| 방법             | 핵심 아이디어                        | 비유                               |
| -------------- | ------------------------------ | -------------------------------- |
| Clique(클릭) 확장  | 같은 하이퍼엣지 안 노드끼리 전부 1:1 연결      | 회의 참석자 5명을 서로 다 아는 사이로 이어버림      |
| Star(별) 확장     | 하이퍼엣지 자체를 새 노드로 만들어 원래 노드들과 연결 | "회의"라는 가상 노드를 만들어 참석자들을 그 노드에 연결 |
| Line(라인) 확장    | (노드, 하이퍼엣지) 쌍을 새로운 노드로 취급      | 클릭+별 장점을 합친 통합형                  |
| CS 확장          | 클릭과 별을 섞은 하이브리드                | -                                |
| Multi-level 확장 | 하이퍼엣지 크기/계층별로 단계적으로 분할         | -                                |
| Hyperedge 확장   | 하이퍼엣지끼리 겹치는 정도(교집합)로 새 그래프 구성  | -                                |


### 확장 과정에서 발생하는 정보 손실 3가지

- **Non-recoverability**: 일반 그래프에서 원래 하이퍼그래프를 정확히 복원 못 함
- **Tie-weakening**: 원래 강했던 다자 관계가 여러 개의 약한 2자 관계로 흩어짐
- **Multi-cloning**: 하나의 하이퍼엣지가 여러 번 중복 표현되어 과대평가됨

이 손실을 정량화하는 지표가 **MILEAGE**입니다. (확장 → 노드 벡터화 → 하이퍼그래프 복원 → 점수 계산의 파이프라인으로, 복원된 하이퍼그래프와 원본의 차이를 점수화)

## 3. HyperGC 본론


### (1) 배경 문제의식


하이퍼그래프의 노드를 벡터로 바꾸는 것을 **표현 학습(Representation Learning)**이라 합니다. HyperGC는 그중 **생성형(Generative) 자기지도학습** 방식에 집중합니다.

> **자기지도학습**: 사람이 붙인 정답 라벨 없이, 데이터 자체의 구조(예: "이 노드들이 원래 하나의 하이퍼엣지였다")를 정답 삼아 학습하는 방식.

**생성형 HRL** = 하이퍼엣지가 어떤 노드들의 조합으로 만들어지는지를 모델이 직접 예측/생성하도록 학습시키는 접근.


기존 방법의 문제 2가지:

1. 기존 생성 모델은 보통 **한 번에 노드 하나씩** 예측하는 방식(자기회귀적)인데, 이것이 정말 "하이퍼엣지 전체를 생성한다"고 볼 수 있는지 의문 → 논문 제목의 **Full Hyperedge Reconstruction**(하이퍼엣지 전체를 온전히 복원)이 여기서 나온 것으로 보임
2. **Unstable negative sampling**: 학습 시 "존재하지 않는 가짜 조합(음성 샘플)"을 어떻게 뽑느냐에 따라 학습이 불안정해지는 문제

### (2) 하이퍼엣지가 자연스럽게 만들어지는 3가지 경로

- **Expansion**: 기존 관계에서 노드가 늘어남
- **Contraction**: 기존 관계에서 노드가 줄어듦
- **New Structure**: 완전히 새로운 관계가 생김

### (3) HyperGC의 3단계 구조


**① Node Encoding (노드 벡터화)**
각 노드를 저차원 벡터로 임베딩.


**② HyperEdge Generation (하이퍼엣지 생성)**
기존 방법(partial reconstruction)과 달리 **Progressive Selection Strategy(점진적 선택 전략)**를 사용합니다. 목표 하이퍼엣지 크기가 될 때까지, 매 반복마다 **Attention 메커니즘**으로 "지금까지 뽑은 노드들과 가장 관련 있는 다음 노드"를 하나씩 추가합니다.

> **Attention**: 여러 후보 중 지금 문맥에서 더 중요한 것에 가중치를 매겨 반영하는 방법.

$$
\text{Attention}(q, k_i) = \frac{\exp(q \cdot k_i)}{\sum_j \exp(q \cdot k_j)}
$$


query $q$(지금까지 선택된 노드들의 정보)와 각 후보 노드의 key $k_i$ 사이 유사도를 정규화해 다음 노드 선택에 확률적 가중치를 줍니다.


**③ HyperEdge Evaluation (하이퍼엣지 평가)**

- **Cross-entropy 기반 평가** (Dynamic Target Loss Cross-Entropy): 예측 확률과 실제 정답 분포의 차이를 측정.

$$
H(p, q) = -\sum_i p_i \log q_i 
$$


$p$: 실제 정답 확률, $q$: 모델 예측 확률 분포

- **대조 학습(Contrastive Learning) 기반 평가**: 진짜 하이퍼엣지(양성)는 서로 가깝게, 가짜 조합(음성)은 멀어지도록 학습.

$$
\mathcal{L} = -\log \frac{\exp(\text{sim}(z, z^+)/\tau)}{\sum_{j} \exp(\text{sim}(z, z_j)/\tau)}
$$

- $z, z^+$: 양성 쌍 (진짜 관계에 있는 두 벡터)
- $z_j$ : 음성 샘플 포함 전체 후보
- $\text{sim}(\cdot,\cdot)$ : 보통 코사인 유사도
- $\tau$ : temperature (작을수록 확실한 것에 더 민감)

### (4) 지적 사항과 반박

1. **순서 문제**: 하이퍼엣지는 원래 순서 없는 "집합"인데, 생성 과정은 노드를 순서대로 추가함 → 실험적으로 노드 추가 순서를 바꿔도 정확도의 표준편차가 크지 않아, 순서가 결과에 큰 영향을 주지 않는다고 결론.
2. **효율성 문제**: 순차 생성에 **LSTM**을 사용해 복잡도가 커짐 → 목표 크기만큼만 생성하도록 제한하면 안정성과 효율을 동시에 확보 가능.

### (5) 성능과 의의

- **정확도**: 대부분의 비교 대상보다 우수
- **확장성**: 최고는 아니지만 준수한 수준
- **의의**: 기존 생성형 HRL이 "노드 하나씩만 보고 예측"하던 한계를 지적하고, "하이퍼엣지 전체를 점진적으로 생성 + 대조학습으로 검증"하는 방식으로 개선

## 4. 핵심 용어 정리


| 용어                              | 쉬운 정의                                    |
| ------------------------------- | ---------------------------------------- |
| 노드/정점 (Node)                    | 그래프에서 하나의 개체(사람, 논문 등)                   |
| 엣지 (Edge)                       | 노드 2개를 잇는 관계선                            |
| 하이퍼엣지 (Hyperedge)               | 노드 여러 개(2개 이상)를 한꺼번에 묶는 관계               |
| 표현 학습 (Representation Learning) | 개체를 컴퓨터가 계산하기 좋은 벡터로 바꾸는 학습              |
| 자기지도학습 (Self-supervised)        | 정답 라벨 없이 데이터 자체 구조를 정답 삼아 학습             |
| 생성형 모델 (Generative model)       | 데이터를 새로 만들어내는 방식으로 학습하는 모델               |
| Negative sampling               | 학습 시 정답이 아닌 가짜 예시를 뽑아 대조시키는 기법           |
| Attention                       | 여러 후보 중 지금 중요한 것에 더 큰 가중치를 주는 메커니즘       |
| LSTM                            | 순서가 있는 데이터를 이전 정보를 기억하며 처리하는 신경망 구조      |
| Cross-Entropy                   | 예측 확률과 실제 정답 분포 사이 차이를 재는 손실 함수          |
| Contrastive Learning            | 비슷한 것끼리는 가깝게, 다른 것끼리는 멀게 벡터 공간을 학습시키는 방법 |
