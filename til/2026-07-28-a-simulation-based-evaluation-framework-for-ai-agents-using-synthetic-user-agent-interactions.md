        ### 에이전트 평가 관련 주요 문제

        - 평가 비용이 높아 에이전트 기반 평가 방식 도입 아이디어가 논의됨
        - **편향(편량) 문제**: 편향이 누적되면서 에이전트를 과대평가하는 경험이 있었음
        - 원인 분석이 어렵다는 문제도 제기됨
        - 좋은 점수가 나오더라도 에이전트 순위(순식)의 신뢰성 문제가 존재함

        ### 리서치 컨셉 소개

        - 팀에서 설계한 리서치 컨셉이 소개됨
        - **세션 구성**: 메뉴, 세션 종류 및 관련 정보 포함
            - **오페라(Opera)**: 아마존 웹 행동 모드 기반
            - **페스티벌(Festival)**: 자유로운 대화 데이터셋 기반
        - 행동 데이터를 보존하기 위한 방안 포함

        ### 딥시크(DeepSeek) 모델 기반 테스트

        - 현재 딥시크 모델을 기반으로 테스트가 진행 중
        - 모델의 동작 방식을 이해하고 모니터링하는 단계

        - **추천 이벤트**를 대상으로 한 평가 방안도 논의됨 (미완결)
